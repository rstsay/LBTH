## #19 跨地點遊戲選擇與完成場次統計

**Status:** 程式已實作；尚待測試與驗收

**User Story**  
身為玩家，我希望無論目前身在何處都能查看可參加的已發布遊戲，並了解自己已完成多少場。

**Scope**
- 玩家可在任何有網路的地點載入已發布遊戲目錄。
- 目錄只提供尚未完成的遊戲供加入；伺服器拒絕重複加入已完成遊戲。
- 顯示已完成遊戲數／已發布遊戲總數。
- 實際尋寶仍須使用前景 Real GPS 到達固定寶藏位置；不包含離線遊玩或動態生成寶藏。

**Acceptance Criteria**
- 遊戲目錄回傳完成場數與已發布遊戲總數；草稿及永久刪除遊戲不計入總數。
- 玩家於任何有網路的地點皆可載入目錄並選擇尚未完成且目前可遊玩的遊戲。
- 已完成遊戲不提供再次加入入口，且伺服器加入端點拒絕重播。
- 完成判定依伺服器有效搜集與啟用目標計算；沒有啟用目標的遊戲不算完成。
- 前端顯示「已完成 X／Y 場」，新發布或永久刪除遊戲後總數正確更新。
- 寶藏搜集仍由伺服器以玩家最新 Real GPS 依既有固定 20 公尺規則驗證。

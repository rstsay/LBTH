# 玩家帳號刪除與遊戲封存管理介面

## User story

身為玩家，我希望能自助永久刪除帳號；身為管理員，我希望按保留規則還原或永久刪除遊戲資料。

## 範圍

- 玩家可在個人資料面板啟動自助永久刪除帳號，明確確認後呼叫 `DELETE /auth/me`；顯示刪除影響及不可復原提示。
- 管理員可查看遊戲封存期限，在 7 天期限內還原資料；還原不恢復遊玩。
- 草稿可明確確認後永久刪除；已結束遊戲僅可在 7 天封存期屆滿後永久刪除，並顯示期限與刪除影響。
- 永久刪除遵循後端唯一權威判斷；仍在保留期限內的事件須去識別化保存，刪除的遊戲貢獻須從排行榜移除。
- 操作遵循既有權限與審計要求。

## 不包含

- 資料保留、清除及刪除後端工作由 #12 追蹤。
- 遊戲生命週期基礎由 #3 追蹤。
- 管理員代玩家刪除帳號、刪除申請清單及帳號復原流程；帳號刪除由玩家自助啟動且不可復原。

## 驗收條件

- [x] 玩家可由個人資料面板明確確認永久刪除帳號；成功後清除本機遊戲狀態並離開登入狀態。
- [x] 管理員在封存期內可還原遊戲資料，畫面說明還原後不恢復遊玩。
- [x] 草稿刪除可明確確認；已結束遊戲封存期內不得刪除，期限屆滿後可明確確認永久刪除。
- [x] 刪除後端操作失敗時保留工作階段並顯示錯誤；操作成功後排行榜與必要去識別事件符合產品規格。
- [x] 管理操作留下審計紀錄；未授權請求遭拒。

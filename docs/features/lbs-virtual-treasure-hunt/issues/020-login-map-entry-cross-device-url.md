# #20 登入入口、草稿地圖回位與跨裝置網址

**Status:** In progress — 前端與文件更新完成；部署網址待確認。  
**Priority:** P1  
**PRD version:** v2.4

## 需求

- 登入頁不顯示信任裝置快速登入按鈕，Magic Link 中的信任裝置選項及後端流程仍有效。
- 每次重新進入草稿地圖時，將地圖中心設在最後新增的寶藏，並維持現有縮放層級；空草稿使用遊戲地圖中心與預設縮放。
- 跨裝置登入須使用可公開連線的正式／測試網域；`PUBLIC_APP_URL` 與瀏覽器使用的網址一致。

## 驗收條件

- [x] 登入頁不再建立或顯示信任裝置快速登入按鈕。
- [x] 重新載入草稿資料後，地圖中心取最後一筆新增寶藏位置；重用同一地圖實例時不重設縮放。
- [x] 無寶藏時使用遊戲設定的地圖中心。
- [x] 開發環境若 `PUBLIC_APP_URL` 指向 localhost 或私有 IPv4 位址，啟動時顯示跨裝置 Magic Link 無法開啟的提示。
- [ ] 設定外網測試網址至 `.env` 的 `PUBLIC_APP_URL`，由另一台裝置開啟 Magic Link 並完成登入。

## 根因

另一台裝置上的 `localhost` 指向該裝置本身。現有 Magic Link 驗證網址由 `PUBLIC_APP_URL` 組成；目前本機 `.env` 使用區網網址 `http://192.168.0.68:3000`，外網裝置無法連線，因此跨外網登入會再次失敗。
